# 藏译汉 Agent 流水线说明

> 本文说明整条翻译流水线：用到哪些文件、各自内容与作用、存放位置，以及**接到校正版后如何修正各文件**（回流）。
> 面向：新会话开工者、维护者、以及想了解「越用越准」机制的用户。

## 一、总设计

这是 **RAG（检索增强）而非微调** 的翻译 agent：不靠模型记忆，而是每次把「本传承已定稿的知识」检索出来、注入 prompt。知识分 **五层**，各有归档处；校正就往对应的「家」放，才能扩散到后续翻译。

| 层 | 归档 | 生效机制 |
|---|---|---|
| 术语（词→词） | `glossary/glossary.tsv` | 藏文精确匹配（含格助词剥离） |
| 译例·文风（整句） | `review/*_parallel.txt` → `tm_*.jsonl` | 音节 Jaccard 相似度检索 |
| 法义/教义 | `notes/法义.md` | **恒常注入** prompt |
| 句法/文法 | `notes/句法.md` | **恒常注入** prompt |
| 行文风格 | `notes/文风.md` | **恒常注入 + 润色遍** |

## 二、文件地图

### 🟢 核心人工资产（进 Git，永久，是「越用越准」的本体）

| 文件/目录 | 内容 | 作用 |
|---|---|---|
| `glossary/glossary.tsv` | 术语表：藏文＼汉译＼频次＼出处 | 强制统一译名；「多义」条给判别线索不强制；「人工校正」条最优先 |
| `glossary/glossary_auto.tsv` | 机器自动抽取的术语候选 | 供人工筛选并入正表，非权威 |
| `review/*_parallel.txt` | 校正定稿的藏/汉逐段对照 | 译例＋文风范本来源；喂 align 生成翻译记忆 |
| `review/*_校订本.md` | 富版校订本（根颂、汉文暗引原文、义理注） | 人可读权威定稿存档；暗引/注**不进** TM |
| `notes/法义.md` | 他空宗见纲要、三自性、破立归属 | 恒常注入——先立义理框架 |
| `notes/句法.md` | 藏文句法解析通则（§1–§14） | 恒常注入——文法/解析取舍 |
| `notes/文风.md` | 行文风格 9 条 | 恒常注入 ＋ 润色遍依据 |
| `notes/科判_品二.md` | 品二科判定稿 | 结构权威 |
| `CLAUDE.md` | 项目说明＋重建命令 | 新会话开工必读 |

### 🔧 流水线代码（进 Git）

| 文件 | 作用 |
|---|---|
| `agent/translator.py` | 主程序：分段 → 组装资料包 → 调模型（两阶段：直译＋润色） |
| `agent/tools.py` | 检索三件套：`lookup_dict` 查词典／`scan_glossary` 查术语表／`search_tm` 查翻译记忆 |
| `agent/prompts/translate.md` | 第一遍系统指令（8 铁律） |
| `agent/prompts/polish.md` | 第二遍润色规范（只改行文、藏文行照抄、段数一致） |
| `pipeline/parse_dict.py`／`parse_gexi.py` | 原始词典 txt → jsonl |
| `pipeline/build_index.py` | jsonl → SQLite FTS5 索引 |
| `pipeline/align.py` | `review/*_parallel.txt` → 翻译记忆 `tm_*.jsonl`（藏块＋汉块配对、剥括号注、判段型） |
| `pipeline/normalize.py` | 藏文 NFC 归一（`nfc`／`lookup_key`／`clean_ws`），全流程共用 |
| `pipeline/extract_terms.py` | 术语自动抽取 → `glossary_auto.tsv` |

### 🟡 可再生大文件（**不进 Git**，`.gitignore` 掉，容器重置后从 GitHub Release 重建）

| 位置 | 内容 |
|---|---|
| `data/processed/dict.sqlite`／`gexi.sqlite` | 两本词典的 FTS5 索引 |
| `data/processed/tm_*.jsonl` | 翻译记忆（align 从 review 定稿生成） |
| `data/raw/dictionaries/*.txt` | 藏汉大辞典／格西曲扎原始文本 |
| `data/raw/parallel/*.txt` | 两本范文（宝性论大疏、极广胜乘中观决定）原始对照 |
| `data/raw/source_texts/*` | 待译原文＋机器草稿译文（临时，等校正） |

> **关键分界**：人工资产（glossary/review/notes）进 Git 永久；可再生索引（data/processed）不进 Git、随时重建；原始素材放 Release（持久）。

## 三、翻译一段的数据流（`agent/translator.py`）

```
藏文原文（先存 data/raw/source_texts/ 并做 OCR 归一：如 གྱྀ→གྱི、གླཽ→གློ、剥游离空格）
   │
   ▼  build_packet(text)   组装「第一遍资料包」，注入顺序：
   ├─ ① prompts/translate.md（8 铁律）
   ├─ ② notes/法义.md → 句法.md → 文风.md（三笔记层，恒常注入，先立框架）
   ├─ ③ 待译原文（split_segments：先尊重原文换行=自然段，段内只在句末终结词 rdzogs tshig 处断句，绝不腰斩）
   ├─ ④ 术语约束：scan_glossary(text) → 强制词 + 多义词（含格助词剥离最长匹配）
   ├─ ⑤ 词典释义：lookup_dict 对术语表没覆盖的多音节词查两本 sqlite
   └─ ⑥ 参考译例：search_tm 每段音节 Jaccard≥0.15 取 top-2（文风范本）
   │
   ▼  _run_claude(packet)  第一遍 → 【准确直译稿 draft】
   │    防护：中性目录运行（不加载仓库 CLAUDE.md，避免内层递归误跑 pipeline）
   │         + append-system-prompt 锁定「只输出译文、禁用工具、禁反问」
   │
   ▼  (默认 --polish) build_polish_packet(draft)= polish.md + 文风.md + 术语约束 + 直译稿
   │    _run_claude 第二遍 → 【定稿体润色稿】
   │    段数校验兜底：藏文行数若变（并/拆段）→ 弃用润色、退回直译，防对照错位
   │
   ▼  写出 *_译文.md（藏汉逐段对照）；润色时纯直译稿另存 *_直译.md（供 diff 提炼文风）
```

- `--packet`：只输出资料包不调模型，核对召回质量。
- `--no-polish`：只要纯直译，跳过润色遍。
- `--model claude-opus-4-8`（主力）／`claude-fable-5`（难点·终校）。

## 四、接到校正版后，如何修正各文件（回流）

按**校正的性质**分类归档——**放对了才会扩散到后续翻译**（见第一节表）。

**每次回流的固定七步：**

1. 建 `review/gzhanstong_X_parallel.txt`（只放藏↔汉译文对；OCR 归一；字符校验；**汉文暗引/义理注不进** TM）。
2. `python3 pipeline/align.py review/..._parallel.txt --source "…校订本(用户认可·文风范本)" --out data/processed/tm_X.jsonl`。
3. 建 `review/gzhanstong_X_校订本.md`（富版：根颂＋暗引原文＋注）。
4. 术语更正并入 `glossary/glossary.tsv`（新增标「人工校正」＝最优先，或「多义」＋判别线索；**修误抽**，如 `དག་པ་གཉིས་ལྡན` 所知→具二清净、删 `ཆོས་དབྱིངས→自性` 重条）。
5. 法义/句法/文风类校正 → 相应 `notes/*.md`（提炼「换词也成立」的通则）。
6. 接线：`agent/tools.py` 的 `TM_FILES` 加一行；`CLAUDE.md` 重建清单加一行 align。
7. commit ＋ push 到开发分支。

> **为何暗引汉文/义理注不进 TM**：TM 是藏↔汉译文的相似度库与文风范本，混入汉文原典或注解会污染检索与文风；它们只进人可读的 `校订本.md` 存档。

## 五、开工前重建（容器是临时的）

新会话/容器重置后，`glossary`／`review`／`notes` 在 Git 里直接有；但 `data/processed/`（词典索引＋TM）没了。`CLAUDE.md` 存了完整重建命令：从 Release 拉原始词典/范文 → `parse_*` → `build_index` → 对每个 `review/*_parallel.txt` 跑 `align.py`。

**开工先检查索引：**
```bash
ls -lh data/processed/dict.sqlite data/processed/gexi.sqlite 2>/dev/null
```
不存在则按 `CLAUDE.md` 的重建段执行。

## 六、命令速查

```bash
# 看资料包（不调模型）
python3 agent/translator.py --text "藏文…" --packet
# 翻译（默认两阶段：直译+润色；另存 *_直译.md）
python3 agent/translator.py --file 待译.txt --out 译文.md
# 只要纯直译
python3 agent/translator.py --file 待译.txt --out 译文.md --no-polish
# 回流对齐（校正版 → 翻译记忆）
python3 pipeline/align.py review/X_parallel.txt --source "…" --out data/processed/tm_X.jsonl
```
