## 三、根颂（`སྐྱེ་བ་རྣམ་པ་བཅུ་བཞི་ལ…`）14 能立 → 14 生

| 颂·能立 | → 生 |
|---|---|
| 因 `རྒྱུ` | ①初起（胎中初生） |
| 量之差别 `ཚད་ཀྱི་ཁྱད་པར` | ②续起（渐增生） |
| 长养无义不应理 `རྒྱས་པ་དོན་མེད་མི་རུང` | ③长起（四因长养） |
| 作所依不可能 `རྟེན་ཉིད་དུ་མི་སྲིད` | ④依起（根境为识所依） |
| 住·不可能 `གནས་པ་ལ་མི་སྲིད` | ⑤变起（贪嗔身变） |
| 初不坏终不变 `དང་པོ་མི་འཇིག་མཐར་མི་འགྱུར` | ⑥熟起（年岁渐熟终灭变） |
| 下劣 `དམན` | ⑦劣起 |
| 殊胜 `ཁྱད་པར་འཕགས` | ⑧胜起 |
| 明 `འོད་གསལ་བ` | ⑨明起 |
| 无明 `འོད་མི་གསལ` | ⑩无明起 |
| **无（次第）往…不应理 `འགྲོ་མེད(…མི་རུང)`** | **⑪异处起（往他境）** |
| **住·不应理 `གནས་པ་མི་རུང`** | **⑫种起（具种子）** |
| 最后（蕴灭）不可能 `ཐ་མ་ཉིད་མི་སྲིད` | ⑬无种起（阿罗汉最后蕴灭） |
| 随心转故 `སེམས་ཀྱི་རྗེས་སུ་འཇུག་པའི་ཕྱིར` | ⑭像起（影像生） |
| 一切有为皆刹那 `འདུས་བྱས་ཐམས་ཅད་སྐད་ཅིག་མ` | 结论 |

**两「住」之辨**：⑤`གནས་པ་ལ་མི་སྲིད`（住·不可能）vs ⑫`གནས་པ་མི་རུང`（住·不应理），颂以 `མི་སྲིད`／`མི་རུང` 二字区分，勿混。

## 四、本会话义理/译法问答（6则·留作 diff 与教学）

1. **`སྐྱེ་བ`→「生」非「出生」**（客观通于一切有为生起）——已入 glossary 恒常校正。
2. **`…འགྲོ་བ་ལ་དེ་རུང་གི…གནས་པ་ལ་མི་རུང`**：极性＝刹那相续而行→应理 / 唯住一刹那→不应理；否定 scope 已厘清。
3. **`ལས་འགག་པ་ནས་ས་བོན་བཏབ་ཟིན` 的 `ནས`**：界点俱成（业一灭讫即种植讫），非「业灭后隔刹那才植」；同句三接续词梯度 `པས་ན…ལ`(进行并发)→`ནས`(完成界点)→`དེ་ནས`(其后次第)。详句法§43。
4. **「此论之刹那无分已遮」句（判教）**：非《庄严经论》破无分（唯识本许无分），而是驳「据说无分判弥勒为唯识师」——以论自身「初不坏终不变」显刹那有分而回护之。详句法§42。
5. **`དེ་གཉིས`（彼二者）＝声闻·独觉二种阿罗汉**（回指 `ཉན་རང`；`彼二者之种子`之所属关系排除「蕴相续与种子」读）。
6. **`གཟུགས་བརྙན་ཙམ་དུ་སྐྱེ་བ` 的 `ཙམ་དུ`＝「仅/唯…地」**：所现仅是影像·无实·唯随心，故刹那现没；「仅」落在「影像」。
