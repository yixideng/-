# 《他空大中观》品四 · 习气新旧安置 · 因果俱时（破法称异时诘难） · 成立染污意（理证）—— 校订本（用户译稿·认可稿 · 文风范本）

> 要义：
> ①**总纲根颂**——新旧习气二者皆滋养；熏习**与现行同时**（`དུས་མཉམ`），其种子之能用「从第二刹那起」方存续；嗔心现起之当刹那即熏，若待其相湮没之第二刹那才安置，则「诚为希奇（极不应理）」。
> ②**论题一·新旧习气如何安置**（`བག་ཆགས...འཇོག་པའི་ཚུལ`）——印度瑜伽行师异说（有唯滋养旧、有唯滋养新）；**自宗无著兄弟：新旧二者皆滋养**。「旧」＝无始来阿赖耶中已有者（其时之边际唯佛智知）；「新」＝此后新熏者（历无量劫，边际亦唯佛知）。
> ③**阿赖耶上习气二分**——已行（`སྤྱད་ཟིན`）之习气＝依缘觉醒、果已成熟者，虽不再生果，仍以**残留（`ལྷག་རོ`）**方式住阿赖耶；未行（`སྤྱད་མ་ཟིན`）之习气＝未熟，以**种子**方式住。（与 4.5 的种子分/异熟分呼应。）
> ④**论题二·安置习气之因果：同时抑前后？答：同时**（`དུས་མཉམ`）——猛利嗔心生之当刹那，即以「能依所依之因果」方式熏习阿赖耶（现行为能依、种子为所熏），种子之能用自第二刹那起存续。反证（第一刹那相显明时熏 vs 第二刹那湮没时熏）：熏必在相显明之当刹那，否则不应理。
> ⑤**破法称「一切因先有」之诘难——枢纽：分判两种因果**：
>   - **生实体之因果**（`ངོ་བོ་བསྐྱེད་པའི་རྒྱུ་འབྲས`，同类相续能生自体，如种→芽）＝**异时·因在果前**；法称「一切诸因皆先有」专就此说，本论亦全盘承许。
>   - **能依所依之因果**（`རྟེན་བརྟེན་པའི་རྒྱུ་འབྲས`）／**差别所生之因果**（`ཁྱད་པར་བསྐྱེད་པའི་རྒྱུ་འབྲས`，如「小瓶」观待「大瓶」而立、如异熟果与所依处）＝**前后无决定·俱时**。
>   - 阿赖耶习气安置属**后者（俱时）**，故与法称（专主前者）**不相违**。教证补强：佛说「六因」等诸多种（其中俱有·相应与果俱时），故「是因则必在果前」不成立。
> ⑥**会通法称「一时一识」**——虽同一刹那阿赖耶能顿生诸不相顺转识，然一「极显明、贪色之强识」**夺去「缘声之等无间缘（`དེ་མ་ཐག་རྐྱེན`）」之力**，故耳识虽以阿赖耶为因而不显；结：六转识虽俱起，皆从阿赖耶生，非从他因。
> ⑦**转入·成立染污意（理证三式）**（`ཉོན་ཡིད...རིགས་པས་སྒྲུབ་པ`）：若无染污意（末那），则——
>   - **㈠有漏善难**：与身见（`འཇིག་ལྟ`）相应之有漏善不可能。因末那眷属之身见是**有覆无记**，能与有漏善相应；六识聚眷属之身见则不与有漏善相应。
>   - **㈡二定无别难**：无想定与灭尽定应无差别。别在——灭尽定灭**七识**；无想定**具染污意**、仅遮六识。故说圣者不生无想天，正因（凡夫无想定中）尚有染污意故。
>   - **㈢我执相续难**：我执之坚固相续不成。因六识聚身见**数数间断**；末那身见则**乃至未得圣道相续不断**。
>
> 术语·校勘：
> - **新增术语**（已并入 `glossary/glossary.tsv`）：`ངོ་བོ་བསྐྱེད་པའི་རྒྱུ་འབྲས`＝生实体之因果（生自体因果·异时）、`རྟེན་བརྟེན་པའི་རྒྱུ་འབྲས`＝能依所依之因果（俱时）、`ཁྱད་པར་བསྐྱེད་པའི་རྒྱུ་འབྲས`＝差别所生之因果（俱时）、`འགོག་སྙོམས`＝灭尽定。
> - 已有沿用：`དེ་མ་ཐག་རྐྱེན`＝等无间缘、`ཉོན་ཡིད`＝染污意、`འཇིག་ལྟ`＝坏聚见/身见（萨迦耶见）、`སྒྲིབ་ལུང་མ་བསྟན`＝有覆无记、`འདུ་ཤེས་མེད་པའི་སྙོམས་འཇུག`＝无想（等至）定、`ལྷག་རོ`＝残留（已熟习气之留存态）。
> - `ཐོགས་མེད་སྐུ་མཆེད`＝无著兄弟（无著·世亲）、`རིགས་པའི་དབང་ཕྱུག`/`རིག་པའི་དབང་ཕྱུག`＝正理自在（法称异称，二形并见，皆指 `ཆོས་ཀྱི་གྲགས་པ`）。

> 名相注（用户补入·参考，非藏汉对照正文）：
> - **熏习俱时（据《摄大乘论》）**：熏习被视为能熏（现行心）与所熏（阿赖耶识）在同一刹那「俱生俱灭」的过程——正是本段「因果同时」在唯识文献中的标准表述。
> - **法称论师**（Dharmakīrti，约 7 世纪）：古印度因明学大师，陈那（Dignāga）之后因明集大成者；《量释论》（Pramāṇavārttika）等「因明七论」为藏地各派必修之逻辑与量论核心。
> - **六因**（能作、俱有、同类、相应、遍行、异熟）：其中**俱有因、相应因与果俱时**，同类·遍行·异熟才是因在果前。故「因则必在果先」不成立——此即根颂「安立因之时有诸多相（`རྒྱུ་ཡི་འཇོག་མཚམས་རྣམ་པ་དུ་མ`）」所指。
> - **法称「一时一识专注」如何会通**：那个特别强的贪色之识，会削弱「缘声之等无间缘（`དེ་མ་ཐག་རྐྱེན`）」之力，故耳识虽有阿赖耶为因却不显——能俱生（合本论）而实际专一（合法称），两不相违。

│    ├ 诸师异说：唯滋养旧 / 唯滋养新
│    ├ 自宗（无著兄弟）：新旧二者皆滋养
│    ├ 新旧之别：旧＝无始已有（边际唯佛知）；新＝此后新熏（历劫·边际唯佛知）
│    └ 阿赖耶上习气二分：已行（异熟已熟·残留住） / 未行（未熟·种子住）
│
├─ 论题二  安置习气之「因果：同时抑前后？」→ 答：同时 ──────
│    ├ 正立：猛利嗔喻——当刹那即熏（能依所依之因果），种能自次刹存续
│    ├ 反证：熏必在「相显明之第一刹那」；若待「相湮没之第二刹那」才熏 → 不应理
│    ├〔颂〕生实体因果有先后；差别生/所依处不定；与法称不违
│    ├〔颂〕不同种类同时生；强识夺缘；故不从阿赖耶外生
│    ├ 破法称「一切因先有」＝＝【枢纽·分判两种因果】
│    │    生实体因果（种芽）＝异时·因在果前 ← 法称专就此说，本论亦许
│    │    能依所依/差别所生因果（小瓶观待大瓶）＝俱时·无前后 ← 习气安置属此
│    ├ 教证补强：佛说「六因」等（俱有·相应与果俱时）→ 因不定在果前
│    ├ 会通「一时一识」：强识夺「缘声之等无间缘」→ 俱生而实专一
│    └ 再界定：法称「因在果前」专就『生实体因果』（若俱时则果前无因、因失生果之能）
│
└─ 转入新科  成立染污意 · 理证（教证待续）────────────
     ㈠ 无末那 → 与身见（有覆无记）相应之有漏善不可能
     ㈡ 无末那 → 无想定/灭尽定无别（灭尽定灭七识；无想定仅遮六识·具末那）

> **为何读来「结构不清」**（校订者按）：①本段是藏地论典典型的**「颂—释—颂—释」交织**，两处论中偈颂（生实体因果 / 不同种类同时生）夹在长行释论之间，非另起主题；②**「因果同时 vs 前后」被反复咬**——设问答 → 偈颂 → 破法称 → 六因教证 → 再界定，看似重复，实为**层层防难**（每回合从不同角度堵法称异时因果的诘难），其真正枢纽只有一个：**分判「生实体因果（异时）／能依所依因果（俱时）」**，抓住此点全段即通；③论题二收尾后**径接新科「成立染污意」**，中间无显眼过渡句，易误为同一论题。
