# review/ —— 人工校正与反馈（进仓库，永久保存）

这里放**翻译之后你人工校正产生的文件**——也就是让系统越用越准的那些成果。
本目录随 Git 推送到 GitHub，容器销毁也不会丢。

## 存什么

| 文件 | 内容 |
|---|---|
| `<经名>_审校.md` / `.docx` | 藏汉对照审校稿，你在上面直接改译文 |
| `<经名>_corrections.tsv` | 从审校稿提炼的修改：藏文｜原译｜改后译｜类型 |

## 反馈闭环（改稿如何回流，让系统变准）

```
机器译文 ──导出审校稿──▶ 你在 review/ 里改
                              │
                    ┌─────────┴─────────┐
              术语级修改              整句级修改
                    │                     │
        更新 glossary/glossary.tsv   补进翻译记忆
                    │                     │
                    └──────┬──────────────┘
                     下次翻译自动生效，越用越准
```

- **术语改法**（如把某词统一改译）→ 进 `glossary/glossary.tsv`（术语主表）
- **整句改法** → 作为新译例补充，提升文体与相似句参考

> 目录先建好占位。导出审校稿的 `review/export.py` 与回流的 `ingest_feedback.py`
> 在阶段 3 补上；你现在起就可以把手工校正稿放进这里，它是安全的。
