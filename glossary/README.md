# glossary/ —— 术语表（进仓库，永久保存，可手工编辑）

`glossary.tsv` 是整个翻译系统的**术语主表**，也是最核心的人工资产：
它规定「某藏文术语 → 必须采用的规范汉译」，保证全书乃至跨经译名统一。

- 列：`藏文 | 汉译 | 频次 | 出处`
- 频次 = 你已定稿译本中该译法出现次数（越高越权威）
- **可直接用表格软件或文本编辑器修改**：改译法、删错项、加新条，均即时生效
- 翻译时 `agent/tools.py` 读此表，命中即强制采用

## 与自动抽取的关系

- `glossary.tsv`（本表，进仓库）= **权威主表**，人工说了算
- `extract_terms.py` 重跑请输出到 `glossary_auto.tsv`（机器候选），
  人工挑选后并入主表——**绝不让机器重跑覆盖你的手工修订**
